Privacy Policy

Last updated: 2 November 2026

What this app is

rclone Drive Sync is a personal tool used only by its owner, to sync the owner's own files between the owner's own computers and the owner's own Google Drive. It has no other users.

What data it accesses

With the owner's permission, the app reads, creates, changes and deletes files in the owner's Google Drive (the Google Drive scope). It does this only to keep the owner's chosen folder in sync and to store the owner's backups.

How data is used and stored

Files are transferred only between the owner's Google Drive and the owner's own private server. The sign-in token is stored in a private file on that server. Data is not collected, sold, shared with or sent to any third party, and the developer does not receive any of it.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting access

The owner can revoke the app's access at any time at myaccount.google.com/permissions.
