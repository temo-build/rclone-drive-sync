rclone Drive Sync

rclone Drive Sync is a personal, single-user tool that keeps one folder on a private Linux server in sync with the owner's own Google Drive, and copies the owner's encrypted backups to that same Drive.

It is used only by its owner, with the owner's own Google account. It is not offered to the public and has no other users.

Read the privacy policy.
